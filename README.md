# Клуб героев — тестовый paywall

Nuxt 4 + TypeScript, сверстанный по макету Figma Make. Тарифы отдаются через
`GET /api/offers`; CTA отправляет тестовую покупку на `POST /api/purchase`.
Реальная оплата не выполняется.

## Локальный запуск

1. Установите Node.js `^22.22.3`, `^24.15.0` или `>=26.0.0` и создайте базу
   PostgreSQL.
2. Скопируйте `.env.example` в `.env` и задайте `DATABASE_URL` — строку
   подключения к PostgreSQL. Например, используйте бесплатную облачную БД
   Neon или Supabase.
3. Выполните `npm install`, затем `npm run dev`.

При первой покупке сервер создаёт таблицу `test_purchases` и сохраняет ID
тарифа, дату и время, а также случайный ID устройства из HTTP-only cookie.

Для деплоя создайте постоянную PostgreSQL-базу (например, Neon или Supabase) и
задайте `DATABASE_URL` в серверных переменных окружения хостинга. Не передавайте
строку подключения в браузер. У пользователя базы должны быть права на создание
таблицы при первой покупке. `prepare: false` обеспечивает совместимость с
connection pooler облачных PostgreSQL-провайдеров.

Без `DATABASE_URL` тарифы доступны, но покупка вернёт явную ошибку настройки
сервиса — приложение не будет сообщать об успешном сохранении без базы данных.
